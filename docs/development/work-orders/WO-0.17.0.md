## 2. 已定案事項（執行者不得更改）

### 2.1 硬規則：一律用共用表格元件

- **主檔單據**用 `RecordSheet`：檢視與修改是同一個表格版面，修改時格子變輸入框。
- **多筆子表**用 `RecordRows`（項次、＋ 插入、垃圾桶移除）。
- **視窗內的表單**用 `EntryTable`（表頭在左或在上、輸入在格內，`Field presentation="cell"`）。
- 全系統規則（使用者 2026-11-09）：「有表格的地方就不要一個個輸入欄位了，他們本來就應該各自有各自適合的位置」——表格在哪裡就在哪裡改，見 `UI_COMPONENT_CATALOG.md` §1 開頭。
- **禁止**再用 `FormSection`＋一欄一欄往下排的 `Field` 做人事的任何新增／修改畫面。缺元件就先擴充 `src/ui/forms/` 的共用元件並更新目錄，不在人事模組內另寫一套。
- 視窗寬度照目錄規則：短表單 `small`、一般 `medium`、含表格 `large`，一定要指定。

### 2.2 「人員」頁籤：員工資料單（設計稿已與使用者確認）

用 `RecordSheet`，檢視與修改同一版面：

- **第一列**：員工編號｜姓名｜身分證字號（遮罩＋「顯示」；修改時唯讀＋「變更」）｜性別｜出生日期｜綁定使用者（修改時「選擇」）
- **第二列**：門市｜職稱｜僱用型態｜排班方式｜到職日｜年資起算日（空白＝到職日）｜班表排序｜不須檢核
- **第三列**：手機｜市話｜戶籍地址（寬）｜通訊地址（寬；修改時下方勾「同戶籍地址」）
- **第四列**：備註（整列）
- 已離職的員工：多一列「離職日｜離職原因」。
- 新增員工時第二列多「人事狀態」（試用／在職）。
- 資料單下方三張子表（`RecordRows`）：
  - 緊急聯絡人：姓名＊｜關係｜電話＊（至少一筆，沿用現有規則）
  - 學歷：學校＊｜科系｜學位｜畢業年月
  - 工作經歷：公司＊｜職稱｜起年月｜迄年月
- 再下方維持現有卡片：請假、薪資、狀態異動、年資不計期間。
- 現有欄位驗證、必填、手機與市話擇一、身分證字號遮罩與顯示權限，**全部沿用，不改規則**。

### 2.3 「排班」「出勤」「請假」頁籤

- 主畫面（排班表、出勤表、請假總表）的格子版面不改。
- 這三個頁籤裡的**視窗**全部改成 `EntryTable` 表格式：
  - 人員：狀態異動、調薪、年資不計期間（`HrOperationalPage` 的 action 視窗）
  - 請假：請假單／銷假（`HrLeaveDialog`）、給予補休、調整特休應給時數、特休書面通知
  - 排班：排班格編輯、門市人員設定
- 調薪視窗：上方一列「生效日｜計薪方式（月薪／時薪）｜本薪｜原因」，下方 `RecordRows` 津貼子表「項目｜金額｜經常性」。

### 2.4 新增「薪資」頁籤：薪資總覽（設計稿已與使用者確認）

- 頁籤順序：人員｜排班｜出勤｜請假｜**薪資**（手機為底部分頁，用 `ModuleSections`）。
- 上方工具列：搜尋員工、門市篩選、狀態篩選（預設「在職」），右側摘要「在職 N 人・月薪合計 $…（不含時薪人員）」。
- 表格欄位：員工編號｜姓名｜門市｜職稱｜計薪（月薪／時薪）｜本薪（時薪顯示「$196 /時」）｜津貼（每項一個小標籤「全勤 $1,500」）｜月合計（本薪＋津貼；時薪人員顯示「—」）｜生效日｜操作。
- 操作（`soft` 按鈕）：「調薪」開 2.3 的調薪視窗；「歷次／收起」在該列下方展開歷次調薪表（生效日｜計薪｜本薪｜津貼｜原因｜登記人），由新到舊。
- 數字靠右、表頭同欄對齊；金額千分位。
- 資料來源：現有 `hr_salary_records`、`hr_salary_allowances`。**只讀取與沿用既有調薪 API**；可新增一支唯讀 API 一次取得所有員工目前的薪資（避免逐人呼叫），權限同人事模組（目前 SUPER_ADMIN）。
- 手機：用共用 `cy-rt cy-rt-list` 兩行清單（姓名＋月合計／本薪・津貼摘要＋操作）。

- **薪資計算**（依排班、出勤、請假、加班算出每月薪資單、勞健保等）：下一張工單，先與使用者定規則。
- 不改人事的資料表、權限、驗證規則與既有 API 行為（2.4 的唯讀 API 除外）。
- 不改排班表、出勤表、請假總表的主畫面格子。
- 固定一條：不加多餘的測試與防護（共通規則 §11.4，使用者 2026-10-29）。只做本單要求的功能與實際會發生的錯誤處理；不加重複驗證、不會發生的情境檢查、層層 fail-closed、自設上限、安全開關，也不為這些寫測試。

## 5. 實作指引

- 版面寫法參考 `item/ItemSheet.tsx`：一個元件同時負責檢視與修改，`editing` 切換；子表用 `RecordRows`。
- 現有 `RowsBlock`／`RowInput`／`cy-hr-edit-row` 的寫法改用 `RecordRows` 後刪除，對應 CSS 一併清掉。
- 視窗用 `Dialog`＋`EntryTable`，參考新增 BOT、商品設定。
- 薪資頁籤的展開用共用 `ExpandToggle variant="text"` 或 `soft` 按鈕（與 BOT 時間軸一致）。
- 金額、日期輸入沿用共用輸入元件；Enter 跳下一格。
