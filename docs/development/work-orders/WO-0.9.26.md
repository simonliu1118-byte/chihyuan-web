## 1. 背景（使用者原話摘錄，2026-10-21）

- 「業務模組新增一個叫貨，這個模組主要是協助我做進貨單叫貨會比較方便。叫貨模組就像客戶/商品那樣一樣是左半清單右半操作，這個共用元件。操作那邊用 listview 之類的清單的方式給我輸入，會比輸入欄位好操作（人事的出勤我也想改清單）。」
- 「台中、台北、洲美是我（高雄門市）向他們調貨，跟進貨意義上是一樣的。」「我每個週期會送出一張叫貨單，所以表格是拿來檢視/編輯的，存檔就會存到左邊清單可以快速翻看。」
- 「廠商那個頁籤比較特別，在檢視上我會希望很多廠商結合在同樣廠商那個頁籤，草稿可以是結合的，但送出的話要存單獨……方便搜尋叫貨記錄。」
- 「叫貨流程就是切到我要的頁籤，填寫預計送出日期（也可以不填），填入品號品名數量單位（可以填 1 或是 1 箱，會自動把單位拆出來），儲存（可修改），確定沒問題送出，狀態會變更為已送出。等貨到的時候我回填進貨單號和勾到貨狀態，那這樣就會有個入口看到哪些還沒到，這邊可以處理成已到貨（一樣回填進貨單號）、取消、缺貨、其他（自己填），就可以把還沒到的處理掉。」
- 「每一列多加一個廠商品號、廠商品名……如果有填就會自己記進去，下次在這個廠商填這個品號就自動帶出。」「要加匯出 Excel 功能，拿來傳。」

## 2. 已定案事項（不得更改）

1. **權限**：一個 Module Access `ORDERING`（label「叫貨」，route `ordering`），放在左邊導覽「業務模組」群組。所有叫貨 API 需此權限。
2. **頁籤（來源）**：台北｜台中｜洲美｜廠商｜定期中國貨｜自訂中國貨｜＋。
   - ＋ 新增的頁籤都是**單一來源**，欄位同台北。
   - 「廠商」頁籤內每家廠商是一個來源、各自有草稿；預設「全部廠商」合併檢視（依廠商分段，段落標題顯示該廠商條件文字），點廠商進入該廠商頁面，**「送出」按鈕只在廠商頁面內**（不做勾選送出）。廠商頁籤內也有 ＋ 新增廠商；廠商條件（自由文字，例如「滿$5000免運費」）在廠商頁面編輯。
   - 來源可改名、排序、停用（停用不刪歷史；停用的頁籤／廠商不顯示在頁籤列，但歷史單照常可查）。
3. **一張叫貨單 = 一個來源 + 一個週期**；狀態 草稿 → 已送出 → 部分到貨 → 已結案，另可作廢。部分到貨／已結案由明細計算。
4. **草稿**：每個來源可同時有多張（通常 1 張，最多 2～3 張）。切到頁籤（不是在看舊單時）開「預計送出日期離今天（台北日期）最近」那張：例 10/21 有 10/22、10/29 → 10/22；有 10/19、10/29 → 10/19；距離相同取較早；沒填日期的排在有日期之後；全部都沒日期開最新建立的。頁籤上方有草稿選單（切換、＋新草稿）。**每格編輯完自動存檔**（逐格／逐列寫入，不整張重寫），以單純整數版本號做樂觀鎖：衝突時提示「已被其他人修改，請重新載入」。
5. **欄位**（品名、數量必填；其餘選填）：
   - 台北、台中、洲美、廠商、＋新增：**品號、品名、廠商品號、廠商品名、數量、單位、備註**（此順序）。
   - 定期中國貨：分三區「針灸針－單支」「針灸針－氣包袋」「其他」，每區 品號、品名、數量、單位、備註。
   - 自訂中國貨：品號（選填）、品名、規格、數量、單位、備註。
6. **數量**：輸入「1」或「1箱」自動拆成數量 1、單位「箱」（單位欄已有值時以單位欄為準）；拆不出數字（例「各1」）保留原文、黃色提示，該列不計到貨量。
7. **廠商品名空白時自動帶入品名**；品名改它跟著改；使用者手動改過廠商品名後不再跟隨。
8. **廠商品號／廠商品名記憶**：只記使用者**手動**填的（不記自動帶入的）：「來源＋品號（無品號則品名）→ 廠商品號、廠商品名」；下次同來源填同品號／品名自動帶出，不覆蓋已手動填的值。廠商頁籤以該列所屬廠商為來源。
9. **品號帶入**：填品號時，若 `erp_sales_items` 有資料，帶出品名、單位（不覆蓋已填值）。
10. **送出**：按「送出」跳確認視窗（顯示來源、品項數），確認後狀態「已送出」、記實際送出時間、版本 1。送出後該頁籤再打開時依 §2.4 選下一張草稿；沒有草稿就自動開一張新的。
11. **已送出仍可改**：可改數量、增減品項；**每次儲存版本 +1 並留修改紀錄**，紀錄形如「版本 3｜10/22 14:05｜某某｜黃花油 數量 5 → 8」，在單據內可展開查看。草稿階段的自動存檔不留修改紀錄。
12. **到貨**：
    - 到貨登記：ERP 進貨單號「`341A-`」固定，只輸入後段 11 碼數字（前 8 碼須是合法日期，例 `20261019001`），存完整 `341A-20261019001`；填到貨日期；勾選本次到貨的列並填數量（預設剩餘量）。一張叫貨單可登記多次（多張進貨單），也可一次登記多列。
    - 每列的剩餘量可結掉為「缺貨」「取消」「其他（自填原因）」；已到的部分保留。
    - 明細狀態：未到／部分到貨／已到貨（已到 ≥ 叫貨量）／缺貨／取消／其他／不計（數量拆不出數字）。單據：全部列已到貨或已結掉 → 已結案。
    - **不做 ERP 查單**、不做單位換算（到貨量以叫貨單位計）。
13. **未到貨入口**：左邊清單最上方固定一項「未到貨（N）」，列出所有未處理完的明細（來源、單據日期、品名、叫貨／已到／剩餘），可直接做：到貨（填進貨單號、日期、數量）、缺貨、取消、其他。
14. **畫面**：用 `src/ui/layout/MasterDetail.tsx`（客戶／商品同款）。左邊「叫貨紀錄」每列**只顯示來源、狀態、日期**（不列品項數、未到數）；可篩選來源、狀態、日期，搜尋品名、品號、ERP 進貨單號。點舊單右邊進入檢視模式（已送出單可編輯、可登記到貨），按「回到草稿」回到頁籤。
15. **清單輸入共用元件**（放 `src/ui/` 下，之後人事出勤會改用）：表格式逐格輸入；Enter 到下一格、最後一列 Enter 新增一列；刪除列；排序（拖曳或上下移）；必填提示；每格 blur／Enter 觸發 `onCommit` 讓呼叫端自動存檔。
16. **匯出 Excel（拿來傳）**：每張單可匯出 .xlsx，檔名「來源＋yyyyMMdd」（例 `台中20261021.xlsx`），版面比照使用者原檔（§5.6）。
    - 台北、台中、洲美、廠商、＋新增：**只匯出 項次、廠商品號、廠商品名、數量、單位、備註**（不匯出我方品號、品名）。
    - 定期中國貨：依三區分段（區名放在產品編號欄，同原檔）；欄位 項次、產品編號、品名、數量、單位、備註。
    - 自訂中國貨：項次、品號（有填才有值）、品名、規格、數量、單位、備註。
    - 廠商合併檢視可一次匯出，一家廠商一張工作表（只含有品項的廠商）。
17. **進貨輔助串接**：`RestockAssistPage` 表格每列最右邊加「加入叫貨單」按鈕（需同時有 `ORDERING` 權限才顯示）。按下選來源（預設**這個品號上一次加入的來源**）、選草稿（預設依 §2.4 的那張；沒有就新開）、填數量（預設期間淨銷，可改），加入後提示成功。
18. **備份**：叫貨資料是使用者手打的業務資料，應該要能備份；但現行可攜備份總列數上限 500（`worker/backup/portable-backup.ts` `MAX_ROWS`），叫貨資料很快會超過並讓整份備份失敗。本單**先把叫貨表列入 `EPHEMERAL_TABLES` 並加註原因**，在 TODO 新增「可攜備份擴充容量後把叫貨表移回備份」待辦；不要改備份機制。
19. **不做**：舊檔匯入、ERP 查單與核對、單位換算、人事出勤改清單（之後另開工作單）。

- `shared/xlsx-writer.ts`：最小 xlsx 產生器；`shared/ordering-export.ts`：叫貨單工作表版面。

### 5.2 預設來源

- 一般：台北、台中、洲美（順序如此）；定期中國貨（三區）、自訂中國貨；廠商頁籤預設廠商（簡稱與條件文字，使用者同意放入）：永全、嘉品、其他（條件空白）、坤日「網套最少30包／彈繃最少20包」、東昇「滿$5000免運費」、長生堂「最低訂貨12罐」、興基達「滿$5000免運費」、知音「滿$2000免運費」、天德「舒軟最少3箱」、育德「滿$4000免運費」、宏大「滿$3000/自取免運費」、宇晶「最少一件」、大立信「最少10000支」、愛民「滿$3500免運」、綠薰舒「20罐大罐出貨」、老謝、小東「要提醒發票」。
- 建立方式：Worker 在第一次讀取來源清單且表為空時建立（同一 batch、冪等）；不得含地址、電話。

### 5.3 自動存檔

- 每格 commit 時只送該列變更（新增列／更新列／刪除列／排序），帶 `expectedVersion`；Worker 以 `UPDATE … WHERE id=? AND version=?` 檢查，成功 version+1；失敗回 409 `ORDERING_VERSION_CONFLICT`，前端提示重新載入，不得覆蓋。
- 草稿的版本號只用於衝突檢查；已送出單另以 `revision`（版本 1、2…）計數並寫 `ordering_revisions`（§2.11）。

### 5.4 到貨與狀態

- 已到量 = 該列所有 `ordering_receipt_lines.quantity` 加總；狀態用 `shared/ordering.ts` 純函式計算，前後端共用。
- 進貨單號：輸入 11 碼數字、前 8 碼合法日期；存 `341A-` + 數字。同一叫貨單重複同一進貨單號時提示（不擋）。

### 5.5 進貨輔助「加入叫貨單」

- 預設來源 = `ordering_item_last_source`（每次加入後更新）；沒有紀錄時不預選。
- 加入時若該草稿已有同品號的列，詢問「加到既有那列」或「新增一列」。

### 5.6 匯出版面（比照使用者原檔）

- 第 1 列：A 欄「叫貨單 【來源】」（合併 A:D 或 A:E），最右欄「M/D叫貨」（M/D 為預計送出日，沒有則用今天）。
- 第 2 列：欄名。第 3 列起：明細，項次從 1 起算。
- 明細後一列：「備註」（A 欄），其後合併儲存格放單據備註（沒有就空白）。
- 定期中國貨：區名寫在該區第一列的「產品編號」欄（原檔用合併儲存格，這裡寫第一列即可）。
- 自訂中國貨原檔標題是「自訂大陸貨 yyyy/MM月」，本系統統一用「叫貨單 【自訂中國貨】」。

## 6. 驗收清單

- [ ] 左邊導覽「業務模組」出現「叫貨」，只有 `ORDERING` 權限看得到；API 無權限回 403。
- [ ] 預設來源與廠商、條件文字正確建立，且重新整理不會重複建立。
- [ ] 頁籤 ＋ 新增來源、廠商頁籤 ＋ 新增廠商、改名、排序、停用皆可用；停用後歷史單仍可查。
- [ ] 草稿選擇符合 §2.4 的三個例子與兩個邊界（距離相同、無日期），有單元測試。
- [ ] 清單輸入：Enter 移動、最後一列 Enter 新增列、刪除、排序、必填提示；每格自動存檔；兩個分頁同時改同一張草稿時，後存的那邊看到衝突提示。
- [ ] 欄位順序與必填符合 §2.5；數量「1箱」「2.5 包」「各1」三種情況符合 §2.6。
- [ ] 廠商品名自動帶入品名、跟隨與停止跟隨（§2.7）；廠商品號記憶只記手動輸入、同來源下次自動帶出、不覆蓋（§2.8）；品號帶入品名／單位（§2.9）。
- [ ] 送出確認、送出後頁籤開下一張草稿或新草稿（§2.10）。
