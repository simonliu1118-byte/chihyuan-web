## Claude 必須特別複審

- 權限安全：讀者不需發布權；USER/ADMIN 未獲 grant 時無法發送或讀發送名單；SUPER_ADMIN 自帶權限；禁止公司公告與個人通知類型混送。
- 逐人隔離：猜測 Todo ID 不得跨人操作；猜測 notice UUID 不得讀私人通知或回執；收件人有效性 server-side 檢查、不得洩漏真實 CYID 管理名單。
- D1 寫入：新通知、收件者、audit 使用 D1.batch；修改同一張通知時不破壞讀取狀態；migration 重建授權表應保留現有 grants、group membership、foreign keys。
- 備份：四張持久新表對應 schema-columns，舊快照可映入新空表；不將私人資料寫到 Git／測試 log，遵守 R2/GCS 專案保護機制。
- 鈴鐺成本：查詢游標、排序、完整計數與索引；大量未讀或到期不導致全表下載，頁籤切換與讀取立即更新。
- 導覽 UX：桌機／手機左上 CY、登入空 hash、既有深連結、未存資料離開確認、同一頁內不同 ID 導航；ERP 查詢及叫貨在切換時仍能保持執行。
- 可用性：收件人名單僅含現有 app_members projection，無 projection 的 CYID 員工目前不能選；若需擴展應另設 CYID 最小權限名冊 contract，不允許借用管理員後門。
- 認證失效、一般權限變更、未登錄帳號、公告撤回與收件人分頁、手機窄版及手動退回路徑均需確認。
- 第一階段不增加其他模組跨表待審統計，不建立背景推播或聊天系統。
