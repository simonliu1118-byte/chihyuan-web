- User state / business mutation：原 `HrOperationalPage` 及 `HrService`；員工異動仍 `saveEmployee`，薪資記錄仍 `HrService.salary`，權限仍由 `handleHrRoute` CYID SUPER_ADMIN gate。不存在另一套薪資計算或改薪寫入。
