# CY Web 查詢欄位與共用頁首調整（V0.7.35）

- 需求日：2026-10-16。只調整展示，不變更 SMART ERP 檢索、CYID 或 Agent protocol。
- 商品欄位：原單頭的「批號管理」與「有效天數」合併為「批號管理及有效天數」，如 `T:需要且檢查庫存量 / 1095天`；「主供應商」與「主供應商名稱」合併為 `B0016  今日軒`。均仍使用原本 Agent 欄位，無另加相容轉換層。
- 商品上方左右分欄及庫別／批號／歷史表格不改動。合併欄位只改顯示，相關資料不覆寫、不去除。
- AppShell 共用 Topbar 顯示當前模組標題，取代原固定「CY Web」文字；左側品牌仍是 CY Web。
- 模組說明統一保留於 AppRoute 的 `PAGE_META`，Topbar「說明」按鈕開啟共用可關閉 Dialog。所有模組移除重複的頁面 h1／常駐說明，既有新增／重新整理等操作不移走。
- ERP 查詢的「連線憑證 · 已連線／未連線」和憑證管理 Modal 移至共用頁首的 `pageTools`，非 Super Admin 仍只有唯讀連線狀態。
- 行動版恢復頂部頁首（以前隱藏），標題與說明一樣可用。既有分頁、權限、登入與資料查詢不受影響。
- 版本 V0.7.35。沿用既有 GitHub CI 與單站部署，正式驗收結果依 Actions Run 記錄。
