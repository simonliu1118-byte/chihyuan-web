- `src/runtime/modules/ItemOperationalPage.tsx`、`item/ItemSheet.tsx`、`item/item-sheet.css`：商品檢視、新增、修改共用 `RecordSheet`；第一列品號／品名／規格／基準單位＋換算，品名與規格欄同寬；第二列分類／成本／成本稅別／門市／診所／批發／網路價。未稅成本的含稅價僅畫面計算。歷史品號和價格異動只在「修改紀錄」視窗。
- `src/ui/forms/InlineGridField.tsx` 與 `inline-grid-field.css`：格內小表格的價格欄位（平台名稱上排、5 位數以上價格輸入），編輯值與 onChange 來自原商品 draft，沒有第二套狀態。
- `src/runtime/modules/ItemsModulePage.tsx`、`src/App.tsx`、`shared/modules.ts`：商品／瑕疵用 `ModuleSections`；`#defects` 舊網址直達，ITEMS／DEFECTS 各自授權，瑕疵原版面／資料 API 完全沿用。
- `migrations/0061_item_price_tables.sql`、`shared/item.ts`、`worker/item/item-validation.ts`、`item-service.ts`、`item-repository.ts`、`item-persistence.ts`、`worker/http/business-api-routes.ts`：三新表（平台／網路價／批發價）、6 個預設平台、scaled4 價格、商品版本鎖、價格差異 Audit 與原 Item API mutation owner。
- `shared/settings.ts`、`worker/settings/settings-service.ts`、`worker/http/settings-audit-routes.ts`、`src/runtime/modules/ModuleSettingsPanel.tsx`：商品設定維護平台的新增、改名、排序與停用，使用原設定 service 與管理權限。
- `worker/backup/portable-backup.ts`、`schema-columns.ts`、`shared/backup-migration-seeds.ts`、`scripts/validate_schema.py`：三表納入可攜備份與恢復、最新 migration 0061、六個預設平台 seed guard。
- `scripts/item-price-record-sheet.test.mjs`：檢查新 RecordSheet、品名規格等寬、價格 mutation ownership、深連結與備份契約；保留其他既有測試。
