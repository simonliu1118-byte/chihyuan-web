# CYWEB V0.29.4 — 薪資讀該月任用值與薪資到出勤定位日期

## 狀態

- 分支 `cyweb/payroll-month-assignments`，基於 origin/main（V0.29.3）。版本 V0.29.4、Build 0（新的獨立修改項目，Z + 1）。無 migration；未開 PR、未合併、未部署、未碰正式 D1；合成資料測試。

## 內容

- 薪資來源（`SOURCE_SQL`）與 `monthOverview` 改用 `asOfProjection`（`worker/hr/hr-current-values.ts`）：生效日 ≤ 月底的最新紀錄（同日取大 id），無則最早一筆舊值，再退回主檔。
- 月內有生效異動（不含建檔、不含月初 1 日）→ 待補「月中任用異動（欄位 YYYY/MM/DD）：須分段核對」；不做分段計薪。
- 來源快照含月底值與當月異動清單，來源比對仍會讓後補登的異動使草稿失效。
- 人事狀態（留停／離職）本就用有日期的狀態紀錄，已核對、未變。
- 薪資待補「到出勤補正」帶日期；`HrAttendancePanel` 捲動並標示該列 2.5 秒（`hr-attendance-flash`）。
