# CYID Consumer Contract Mirror

This directory is a read-only synchronized mirror of the CYCloud Identity consumer contract package.

- Canonical source: `simonliu1118-byte/CYapps/main/apps/CYCloudIdentity`
- Package membership: `CONSUMER_SYNC_MANIFEST.json`
- Sync command: `bash scripts/sync-cyid-consumer-contract.sh`
- Validation: `bash scripts/validate-cyid-consumer-sync.sh`

Do not edit mirrored contract files here by hand. Permanent CY Web obligations remain in root `PROJECT_RULES.md`; the mirror exists so cross-repository work can read and validate the same CYID contract bytes locally.
