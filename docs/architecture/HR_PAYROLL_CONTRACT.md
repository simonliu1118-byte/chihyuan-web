# 每月薪資契約（V0.21.0，待 Claude 審查）

本契約適用第三批工作分支，尚未合併或部署。沿用 [人事合約](HR_MODULE_CONTRACT.md)、[既有設計](HR_MODULE_DESIGN.md) 及 CYID；不取代身分、排班或假單來源。需求原文見 [確認紀錄](../development/HR_PAYROLL_PLAN.md)，工程證據及尚缺驗收見 [handoff](../handoff/CYWEB-HR-PAYROLL-20261115.md)。

## 入口與權限

人事仍有「人員、排班、出勤、請假、薪資」五頁籤；薪資頁內切換「薪資設定／每月薪資」。前者保留主檔調薪及津貼，後者顯示月份清冊、逐項薪資、公司成本、待補事項與法定表版本。全部使用共用 DataViewToolbar、EntryFields columns／EntryTable、Dialog、cy-op-table／cy-rt、820px RWD；前端不維護薪資公式。

除下列兩條更正路徑外，人事／薪資／設定 API 仍僅 CYID SUPER_ADMIN。指定更正者須同時具有 ADMIN 角色、啟用帳號與有效門市授權；USER 即使有授權資料也不生效。ADMIN 只看指定門市的員工編號、姓名、出勤日期、下班時間與 revision，不能取得證號、薪資、人事主檔、上班卡編輯或加班編輯。每次讀寫由 Worker 重驗，寫入交易內再驗授權及出勤 revision。

## 來源與計算

- 本薪、津貼及生效日直接取`hr_salary_records`／`hr_salary_allowances`，不另存薪資主檔。津貼項目沿用既有自建設定；每月薪資把該筆主檔的月額津貼列入工資，不依「非經常性」標記自行免稅或排除加班基礎。
- 計薪／投保設定為每人有生效日的歷史：全勤適用勾選與金額、部分工時約定正常工時、各項已申報投保金額及各自期間、就保適用、健保月底計收／眷口、勞退雇主與自提率、單位職災率、稅務身分、本人扣繳選擇及扶養人數。不是代辦加退保；不自動猜身分及費率。
- 月薪分母30天；月中本薪／津貼變更按原生效段計算。未滿月、月中異動、留停跨月須確認計薪天數0～30及原因。時薪按當日主檔時薪和已確認正常分鐘計算，不重付已列加班分鐘；固定月額津貼依確認天數折算。部分工時月薪須有每週工時，時薪津貼須有約定月正常工時，不能拿全職240小時盲套。
- 全勤不是預設人人適用；未勾選不自動新增。單次遲到1～5分鐘免扣薪／全勤；6分鐘起扣全部分鐘並取消當月全勤。早退按全部分鐘且取消全勤。一般事假、曠班取消；多原因不重扣為負。普通病假全勤按`金額÷30÷8×小時`扣發，生理假及法定保護事由不取消。
- 普通傷病假年度前30日半薪，超過部分與前三日生理假合併邊界分開；生理假月1日、可拆兩個半天，沿用所有假別半小時單位驗證，年度前3日按分鐘界線併病假。病假與實發全勤分開算，已以勞動部30000＋3000、病假1日的32352元範例驗證。
- 婚、喪、特休、產檢、陪產檢及陪產、公假、補休等依既有法定假別取給薪；事假／家庭照顧不給薪但全勤保護分開。公司自建假須明確給薪比例0～1；法定假比例不開放用一般設定改寫。法定保護可在新假單或既有假單「全勤保護」更正，不從自由文字猜。
- 加班從既有已確認的加班費／補休資料及原日工資率計算，平日／休息日／假日分段，公司連六優惠不自行當免稅法定加班。一般已驗證範圍每日12小時、每月46小時；54／138協議及特殊制度未驗證時列待確認，不能暗自套用。例假緊急出勤須另有明確確認與補假依據。
- 勞／就保分項計算並與官方合計表對照；部分月採30天、每日精度後分項舍入。健保用官方一般受僱者負擔金額表、月底計收事實與最多3眷口。雇主保費／職災／勞退列公司成本，不扣員工；勞退自提另列。保費、勞退和稅各取自己的適用期間，扣繳按實際給付日選表。
- 一般每月薪資的境內扣繳採表或本人選擇5%；5%不超過2000元免扣；非居住者採官方最低工資1.5倍門檻之6%／18%。匯入須核對官方仍有這組費率及免扣規則，變更即阻擋，不能只換CSV卻沿用失效費率。扶養／所得超出官方表範圍列待確認，不套最高格。
- 工資加項月底進位至元、一般扣薪月底捨去不足元；保費依法定分項舍入，扣繳表用官方整數金額。薪資明細顯示各項依據。缺卡、未完成假單、缺級距、未確認投保或其他無法可靠判斷項目，明示待補並禁止確認／發薪標記。

## 結清、快照及交易

草稿→確認→已發薪；確認可撤回為void快照，再開新草稿；已發薪不撤回、不原地更改。每次操作留下原因與Audit。確認及標記發薪均在交易內重跑同一個有界SQL來源快照並比較，關閉「讀完後並行更正」窗口；資料已更動就要求重算，不靜默換數字。

補休到期／終止仍沿原介面產生結清紀錄，本批依原加班月份**已發薪**工資率與加班免稅級距快照算尚餘後段，不拿本月薪資重算。特休沿既有週年／遞延帳，按原年度終結或離職工資基準結清；額外公司額度不自動當法定免稅。確認時唯一消耗來源鍵，避免跨月重付；撤回未發薪確認才釋放該次消耗，歷史紀錄保留。缺原工資快照或部分工時歷年額度先待補，不猜數字。

薪資所屬月、約定次月5日及實際給付日分開。UI預填次月5日，順延後填實際日期；此日期用於清冊／稅版，不代表自動匯款。離職結清不能無條件延至一般發薪日。

## 官方表自動更新

沿既有唯一五分鐘cron於台灣04:00派送每日一次檢查，也可在設定按立即檢查。只接受HTTPS官方白名單，每次轉址驗目標、每請求20秒及1MB串流上限，無D1憑證／AI寫入接口。抓取、正規化與驗證通過就自動導入，沒有年度人工核准步驟；暫時HTTP／網路錯誤保留尚有效舊版，結構異常隔離並阻擋確認，重試成功才解除。

| 項目 | 官方入口／生效證據 |
| --- | --- |

| 勞退 | [6274](https://data.gov.tw/dataset/6274)，JSON全級數及各列生效日 |
| 健保 | [20246](https://data.gov.tw/dataset/20246)，探索健保署CSV，取最新標明年月的一般受僱者表 |

來源解碼去BOM後的文字SHA-256及原文／佐證、生效區間、正規化內容hash、匯入時間與Audit保留於D1並納入原可攜備份。內容相同不每天新增版本；同生效日修訂增加新版本。勞就保／稅表到年末失效，缺新年度資料不能冒用；健保／勞退依原生效日延續到新版。已發薪結果不隨新表覆寫。

## 已知待補／使用邊界

- 沒有遠端D1變更、政府申報／繳費、銀行工作日曆、自動匯款、AI接口或正式資料初始化。
- 沒有自動推估未提供的法定事實。月中投保設定／法定表分段、公傷病保險給付抵充、未滿6個月及短期流產產假、零碎產假與跨月連續曆日給薪等尚未完整自動化，會列待補，不可確認。
- 一般每月薪資模型尚未擴充非每月獎金、兼職所得的獨立稅務處理、健保補充保費、外派／特殊投保身分、54／138協議工時、已發薪沖正與補發清冊；不得把本批當成全情境法務／會計驗收。正式採用前由Claude複核適用員工與公司制度，必要擴充另列修正。
- 未標明連續產假／保護事由的舊假單不從事由自動判斷，須先核對正式紀錄；原薪資主檔已有同名「全勤」會提示核對，避免再加一次或略過扣發。
- 初次導入沒有過往已發薪工資快照者，歷史補休／特休結清列待補；不能把目前成本當作歷史工資。已發薪修正需後續可追溯補扣流程，不直接刪快照。
- UI使用共用820px規則，互動測試不等於1440／390目視；本環境Chromium的socket啟動受限，真實桌機／手機目視仍待補。
