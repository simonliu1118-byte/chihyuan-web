## 入口與權限

人事仍有「人員、排班、出勤、請假、薪資」五頁籤；薪資頁內切換「薪資設定／每月薪資」。前者保留主檔調薪及津貼，後者顯示月份清冊、逐項薪資、公司成本、待補事項與法定表版本。全部使用共用 DataViewToolbar、EntryFields columns／EntryTable、Dialog、cy-op-table／cy-rt、820px RWD；前端不維護薪資公式。

除下列兩條更正路徑外，人事／薪資／設定 API 仍僅 CYID SUPER_ADMIN。指定更正者須同時具有 ADMIN 角色、啟用帳號與有效門市授權；USER 即使有授權資料也不生效。ADMIN 只看指定門市的員工編號、姓名、出勤日期、下班時間與 revision，不能取得證號、薪資、人事主檔、上班卡編輯或加班編輯。每次讀寫由 Worker 重驗，寫入交易內再驗授權及出勤 revision。

## 來源與計算

- 本薪、津貼及生效日直接取`hr_salary_records`／`hr_salary_allowances`，不另存薪資主檔。津貼項目沿用既有自建設定；每月薪資把該筆主檔的月額津貼列入工資，不依「非經常性」標記自行免稅或排除加班基礎。
- 計薪／投保設定為每人有生效日的歷史：全勤適用勾選與金額、部分工時約定正常工時、各項已申報投保金額及各自期間、就保適用、健保月底計收／眷口、勞退雇主與自提率、單位職災率、稅務身分、本人扣繳選擇及扶養人數。不是代辦加退保；不自動猜身分及費率。
- 月薪分母30天；月中本薪／津貼變更按原生效段計算。未滿月、月中異動、留停跨月須確認計薪天數0～30及原因。手填天數低於任職期間且無留停來源，或少於已記錄正常出勤工時時列待補，不可確認；留停依據由Worker讀正式狀態歷史，不接受前端自稱。時薪按當日主檔時薪和已確認正常分鐘計算，不重付已列加班分鐘；固定月額津貼依確認天數折算。部分工時月薪須有每週工時，時薪津貼須有約定月正常工時，不能拿全職240小時盲套。
- 全勤不是預設人人適用；未勾選不自動新增。單次遲到1～5分鐘免扣薪／全勤；6分鐘起扣全部分鐘並取消當月全勤。早退按全部分鐘且取消全勤。一般事假、曠班取消；多原因不重扣為負。普通病假全勤按`金額÷30÷8×小時`扣發，生理假及法定保護事由不取消。
- 普通傷病假年度前30日半薪，超過部分與前三日生理假合併邊界分開；生理假月1日、可拆兩個半天，沿用所有假別半小時單位驗證，年度前3日不併病假，超出部分按分鐘界線併病假。病假與實發全勤分開算，已以勞動部30000＋3000、病假1日的32352元範例驗證。
- 婚、喪、特休、產檢、陪產檢及陪產、公假、補休等依既有法定假別取給薪；事假／家庭照顧不給薪但全勤保護分開。公司自建假須明確給薪比例0～1；法定假比例不開放用一般設定改寫。法定保護可在新假單或既有假單「全勤保護」更正，不從自由文字猜。
- 加班從既有已確認的加班費／補休資料及原日工資率計算，平日／休息日／假日分段，公司連六優惠不自行當免稅法定加班。一般已驗證範圍每日12小時、每月46小時；54／138協議及特殊制度未驗證時列待確認，不能暗自套用。例假緊急出勤須另有明確確認與補假依據。
- 勞／就保分項計算並與官方合計表對照；部分月採30天、每日精度後分項舍入。健保用官方一般受僱者負擔金額表、月底計收事實與最多3眷口。雇主保費／職災／勞退列公司成本，不扣員工；勞退自提另列。保費、勞退和稅各取自己的適用期間，扣繳按實際給付日選表。
- 一般每月薪資的境內扣繳採表或本人選擇5%；5%不超過2000元免扣；非居住者採官方最低工資1.5倍門檻之6%／18%。匯入須核對官方仍有這組費率及免扣規則，變更即阻擋，不能只換CSV卻沿用失效費率。扶養／所得超出官方表範圍列待確認，不套最高格。
- 扣繳（薪資所得扣繳辦法，Claude 2026-11-16 查證）：每月固定薪資，員工已填免稅額申報表→按扣繳稅額表（§5，115年無扶養自90,501起）；未填→全月給付總額5%（§6Ⅰ）；兩種方式每月應扣不超過2,000元皆免扣（§7Ⅰ）。兼職／非每月獎金單次未達起扣點免扣，達起扣點扣5%（§6Ⅱ、§7Ⅱ）。非居住者全月薪資在基本工資1.5倍以下6%，以上18%（扣繳率標準§3）。
- 時薪人員國定假日（使用者 2026-11-16）：原應工作日照給當日工資，出勤另依加班加倍。
- 工資加項月底進位至元、一般扣薪月底捨去不足元；保費依法定分項舍入，扣繳表用官方整數金額。薪資明細顯示各項依據。缺卡、未完成假單、缺級距、未確認投保或其他無法可靠判斷項目，明示待補並禁止確認／發薪標記。

## 結清、快照及交易

草稿→確認→已發薪；確認可撤回為void快照，再開新草稿；已發薪不撤回、不原地更改。每次操作留下原因與Audit。確認及標記發薪均在交易內重跑同一個有界SQL來源快照並比較，關閉「讀完後並行更正」窗口；資料已更動就要求重算，不靜默換數字。

補休到期／終止仍沿原介面產生結清紀錄，本批依原加班月份**已發薪**工資率與加班免稅級距快照算尚餘後段，不拿本月薪資重算。特休沿既有週年／遞延帳，按原年度終結或離職工資基準結清；額外公司額度不自動當法定免稅。確認時唯一消耗來源鍵，避免跨月重付；撤回未發薪確認才釋放該次消耗，歷史紀錄保留。缺原工資快照或部分工時歷年額度先待補，不猜數字。

薪資所屬月、約定次月5日及實際給付日分開。UI預填次月5日，順延後填實際日期；此日期用於清冊／稅版，不代表自動匯款。離職結清不能無條件延至一般發薪日。

## 官方表自動更新

不排程自動抓取（使用者 2026-11-16 定案）：只在人事設定按「更新官方表」時手動檢查。只接受HTTPS官方白名單，每次轉址驗目標、每請求20秒及1MB串流上限，無D1憑證／AI寫入接口。抓取、正規化與驗證通過就自動導入，沒有年度人工核准步驟；暫時HTTP／網路錯誤保留尚有效舊版，結構異常隔離並阻擋確認，重試成功才解除。

## Build2 法定假、月中投保與給付稅務

- 保費／勞退依實際生效日與各項投保期間分段；勞／就保日額截至小數四位後各項月底舍入，30天總額與官方表對照，31日邊界不多算一天；健保仍取月底版本與計收事實。月中全勤／約定工時異動尚須核對，不能誤以為保險分段等於所有工資規則已自動分段。
- 產假正式假單必須是連續56／28／7／5曆日，含例休，不接受拆成零碎半小時。一般假仍最低半小時。跨月／跨年計算須有完整正式假單；六個月年資、最近月工資及較高的六個月平均日工資依已核對來源處理。未滿六月半薪／短期流產無薪與全勤保護分開；短期流產也可依法另選普通病假，依實際核准假別計算，不替員工擅改。
- 公傷病以原領日工資及醫療期間核對、每月同事故已給付抵充（尚未給付也須明確記0）；不能把其他補助無限抵扣。時薪原日工資×30填核對基準，依實際排班排除例假，缺排班先待補。法定補償與一般工資稅務性質分開。基準／平均日工資是有證明的計算事實，不另建薪資主檔。
- 投保／扣繳profile補給付日的本職或兼職、補充保費身分／免扣證明、投保單位代碼及系統外年內獎金期初額／截止日／來源。無實據不預設0或免扣；系統內已發獎金另累計，不因外部期初截止日漏算。
- 本次非每月獎金與月薪使用同一實際給付日，獎金獨立判定5%起扣點；本職月薪按給付月累計，非居住者同月合計6%／18%，兼職按單次門檻。同日多次給付合併檢查，不拆單繞過門檻。
- 個人補充保費依獎金年累計超過投保額四倍／兼職單次最低工資等規則與有效官方版本計算，受上限限制、元以下四捨五入，不減少課稅工資。公司補充保費為給付月薪資所得總額減受僱者投保額總額的獨立清冊，不扣個人。合法免稅加班費、勞退自提及法定職災補償不混入課稅所得；未核定津貼不只看名稱自行免稅。
- 公司清冊以已發薪所得快照及當月月底投保設定彙總，非已提交的申報快照；僅含本系統發放，系統外支付仍須完整核對，不能直接宣稱是完整政府申報。

## Build2 前期已發薪更正

只追加與原已發薪快照關聯的後月差額，不改／刪原快照。補發工資進當期工資及稅務；經同意追回溢領、保費及扣繳稅的補扣／退還在稅後列項，不自行倒扣當期課稅所得。追回工資須員工明確同意依據，稅／保費更正須核定或可追溯證明；退還總額不得超過原快照該類已扣金額，並在交易內再驗上限。

新增用requestKey冪等；目標月已確認／已發薪不能插入新差額，先撤回未發薪稿或選下一月。確認時唯一保留差額、撤回未發薪釋放、已套用不能直接撤銷；與完整來源guard及Audit同交易。不自動更正政府申報或匯款。

## 已知待補／使用邊界

- 沒有遠端D1變更、政府申報／繳費、銀行工作日曆、自動匯款、AI接口或正式資料初始化。
- 仍不推估未提供的投保／稅務身分、產假平均日工資、公傷原日工資、同事故抵充、系統外獎金及歷史結清基準；資料不足須補齊才可確認。歷史假單須人工核對正式類型與完整期間。
- 獎金目前隨月薪同日發放；不同日期另開獎金批、外派／特殊保險身分、跨投保單位轉換的獎金年累計及54／138工時協議尚未提供完整流程。一般病假如有保險給付差額等特殊事實，須先另核對，不能宣稱所有情境自動結案。
- 原主檔同名全勤須核對，避免重複給；津貼全額列工資，不擅以名稱作免稅伙食額。歷史補休／特休缺原快照先待補。沒有新增正式薪資單列印／匯出模板。
- UI沿共用820px，Host互動不等於1440／390目視；本輪桌面Chromium可開但AT-SPI控制不可用，雲端瀏覽器禁止本機file URL，沒有繞過限制或宣稱目視已完成。
- 全部工程須Claude複核公式、法定邊界、交易、權限及畫面。仍為draft PR，審查通過也不是合併／部署授權。
