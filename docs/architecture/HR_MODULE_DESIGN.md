# CY Web 人事模組設計

> Status: 第一期設計定案（BD-059）；第二、三期為規劃，開工前另行確認。
> 法規依據以勞動基準法（勞基法）、勞基法施行細則、最低工資法為準；條文細節在各期開工前再核對最新公告。

## 1. 分期

| 期 | 內容 | 狀態 |
|---|---|---|
| 一 | 人事主檔、人事狀態、綁定使用者、年資、特休應有天數（週年制）、薪資異動紀錄、最低工資設定 | WO-0.9.20 |
| 二 | 假別與請假、出勤紀錄、特休扣抵與遞延、加班紀錄、員工自助查詢、特休年度書面通知 | 規劃 |
| 三 | 月薪計算、加班費、勞健保、勞退提繳、所得稅扣繳、薪資明細與工資清冊 | 規劃 |

三期完成前，整個模組只有超級管理員可用（BD-059）。

## 2. 第一期資料

### 2.1 人事主檔 `hr_employees`

| 欄位 | 說明 |
|---|---|
| 員工編號 | 唯一，必填（與 CYID 員工編號同格式，可不同號） |
| 姓名 | 必填 |
| 人事狀態 | 試用、在職、留職停薪、離職（由狀態異動紀錄決定，見 2.2） |
| 綁定使用者 | 選填，對應 `app_members`；一個使用者最多綁一筆人事資料 |
| 身分證字號 | 選填；格式檢查（身分證與新式居留證檢查碼）；畫面遮罩 `A12****789` |
| 出生年月日、性別 | 選填 |
| 手機、市話 | 選填 |
| 通訊地址、戶籍地址 | 選填；可勾「同通訊地址」 |
| 到職日 | 必填 |
| 年資起算日 | 預設＝到職日；依勞基法第 10 條（離職未滿三個月再受僱等）可改早 |
| 離職日、離職原因 | 狀態為離職時必填 |
| 備註 | 選填 |

子表：

- **緊急聯絡人** `hr_emergency_contacts`：姓名、關係、電話（可多筆，至少建議一筆）。
- **學歷** `hr_education`：學校、科系、學位／程度、畢業年月（YYYY/MM）。
- **工作經歷** `hr_work_history`：公司、職稱、起年月、迄年月、說明。

### 2.2 人事狀態異動 `hr_status_changes`

每次變更新增一筆：生效日、原狀態、新狀態、原因、經手人。主檔的狀態＝生效日不晚於今天的最後一筆。不可修改舊紀錄；更正以新增一筆並說明原因。

### 2.3 年資不計期間 `hr_seniority_exclusions`

起日、迄日、原因（例如留職停薪）。由超級管理員逐案登錄；系統不自動假設哪種留職停薪不計年資（BD-059 待確認事項）。

### 2.4 薪資異動 `hr_salary_records`

| 欄位 | 說明 |
|---|---|
| 生效日 | 必填 |
| 計薪方式 | 月薪／時薪 |
| 本薪 | 月薪金額或時薪金額（整數元） |
| 津貼明細 | 多筆：項目（設定表 `hr_salary_item_types`，例如伙食津貼、職務加給）、金額、是否經常性給與 |
| 異動原因 | 必填（到職核薪、調薪、職務調整…） |

只能新增；更正以新增一筆。目前薪資＝生效日不晚於今天的最後一筆。

### 2.5 最低工資 `hr_minimum_wages`

生效日、每月金額、每小時金額。超級管理員依勞動部公告自行輸入，系統不內建數字。

新增薪資異動時，「本薪＋經常性津貼」低於當日適用的最低工資（月薪比每月、時薪比每小時）時：**擋下存檔**，訊息列出比對的最低工資與生效日。若尚未設定任何最低工資，顯示警告但允許存檔。

## 3. 特休（週年制，勞基法第 38 條）

以「年資起算日」為準，扣除「年資不計期間」後的實際年資，在每個週年日給假：

| 滿年資 | 給假日數 | 該特休年度 |
|---|---|---|
| 6 個月 | 3 | 滿 6 個月起至滿 1 年前一日 |
| 1 年 | 7 | 滿 1 年起一年 |
| 2 年 | 10 | 〃 |
| 3、4 年 | 14 | 〃 |
| 5～9 年 | 15 | 〃 |
| 10 年 | 16 | 〃 |
| 每多 1 年 | 加 1 日 | 〃 |
| 24 年以上 | 30（上限） | 〃 |

- 有年資不計期間時，之後的週年日往後順延相同天數。
- 第一期只算「應給天數與特休年度起訖」，列出過去與目前年度；請假扣抵、遞延、未休折發在第二期。
- 計算放在 `shared/hr-annual-leave.ts`（純函式，前後端共用），附完整單元測試：剛滿 6 個月、滿 1 年、10 年、24 年、閏年 2/29 到職、年資不計期間順延。

## 4. 權限與個資

- 路由 `#hr`、API `/api/business/hr/*`：後端一律檢查 `SUPER_ADMIN`，其他角色 403；選單只對超級管理員顯示，放在「業務模組」最後。
- 不加入 `CYWEB_MODULES` 模組授權與權限群組（BD-059）。
- 身分證字號：API 預設只回傳遮罩值；「顯示完整」呼叫獨立 API，並寫一筆稽核 `hr_employee.national_id.viewed`。稽核的 before／after 不存完整身分證字號（只存遮罩值）。
- 新增、修改、狀態異動、薪資異動都寫結構化稽核（BD-053／054）；異動紀錄頁本來就只有管理員以上可看，人事事件再限縮為超級管理員可見。
- 人事資料不可刪除；離職以狀態異動表示（勞基法第 23、30 條保存五年）。

## 5. 第二、三期預告（開工前另議）

- **第二期 假勤**：假別依勞工請假規則、性別平等工作法；出勤紀錄（勞基法第 30 條）；特休扣抵、遞延（第 38 條第 4 項）、年度書面通知（第 38 條第 6 項）；加班紀錄（第 32 條上限）；員工自助查詢自己的特休。
- **第三期 薪資**：加班費（第 24 條）、例假休假日出勤（第 39、40 條）、勞保／健保／勞退 6% 提繳、所得稅扣繳、薪資明細（第 23 條）與工資清冊。費率與級距以設定表維護並標生效日。
