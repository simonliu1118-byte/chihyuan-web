# BD-022 — Existing customer-item quote records may be corrected with audit; new commercial prices create new history

**Status:** CONFIRMED

## Decision

CY Web distinguishes a correction of an existing customer-item quotation-history record from a genuine new quotation.

An existing quotation-history record may be edited when correcting data-entry mistakes or other factual errors. Such edits must remain auditable.

A genuine change in commercial terms, price, quantity break, unit or other newly quoted condition is not a correction of the old record. It creates a new quotation-history record under the BD-021 history-preservation rule.

## Correction behavior

When an authorized user corrects an existing quotation-history record, CY Web should record enough audit information to reconstruct the change, including where applicable:

- changed fields / quantity-price break rows;
- previous and corrected values;
- actor;
- timestamp;
- correction reason or note where required by the final UI/workflow.

The corrected record remains the same historical quotation identity; the audit trail explains that the stored record was repaired.

Example:

```text
original data entry: 100 boxes @ 950
actual quoted value: 100 boxes @ 95
=> correct the existing record and retain audit history
```

## New-quotation boundary

If the salesperson later offers a different commercial price or price-break structure, CY Web must create a new quotation-history record instead of rewriting the prior one.

Example:

```text
2026-01-10  100 boxes @ 95
2026-06-20  100 boxes @ 100
=> two quotation-history records
```

The application must not use the correction path as a routine mechanism for replacing historical prices with newly quoted prices.

## Relation to Legacy behavior

The user-facing quotation workflow should continue to follow the useful Legacy customer-item quotation model described in BD-020 and BD-021. The new CY Web implementation adds structured auditability around corrections without converting the feature into a formal SMART ERP quotation-document workflow.
