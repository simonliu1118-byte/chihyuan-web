# BD-047 — CY Web production starts clean; Legacy test data is not migrated

**Status:** CONFIRMED

## Decision

The current GAS / Google Sheets Legacy system has not been placed into production use. Its existing rows are development and test data and are not business records that CY Web must preserve.

CY Web therefore does **not** require a Legacy Google Sheets → D1 production data migration.

The first production CY Web database will start from the new canonical D1 schema and will contain only data entered, synchronized, or explicitly imported for the production CY Web system after the new application is ready for use.

## Consequences

The following Legacy-migration work is removed from the CY Web launch path:

- value-level profiling for migration acceptance;
- Google Sheets → D1 importer;
- `legacy_id_map` or equivalent migration-only identity mapping;
- Legacy row-count / orphan-FK / alias reconciliation as a cutover gate;
- migration dry-run and rollback for the current GAS test dataset;
- preservation of current Legacy test history solely for production migration.

Legacy source and test data may still be inspected when useful for understanding behavior, field semantics, validation, UI flow, or historical implementation choices. They are **reference evidence**, not production source data.

## What remains required

This decision does not remove normal production database engineering requirements:

- D1 schema migrations remain the forward, versioned schema source of truth;
- new production data must still satisfy server-side validation, constraints, permissions, audit, backup, and restore requirements;
- SMART ERP integration/synchronization remains a separate future integration boundary;
- the future SMART ERP item-code renumbering process in BD-011 is a separate production business-data operation and is not the abandoned Legacy-data migration.

## Cutover implication

There is no Legacy-data cutover. Launch acceptance focuses on the new CY Web application, its fresh production D1 database, permissions, workflows, responsive UI, backup/restore, and any explicitly enabled ERP integration.

The old GAS deployment and Sheets may remain available as a development/reference artifact until the user confirms the new CY Web system is stable; they do not need to be imported before retirement.
