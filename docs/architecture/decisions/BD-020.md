# BD-020 — CY Web Quote is a customer-item price record; formal quotations remain in SMART ERP

**Status:** CONFIRMED

## Decision

The Legacy/CY Web `Quote` concept remains a lightweight customer-item quotation/price-history record. It represents one customer plus one item, with one or more quantity-price breaks and related notes/date/salesperson context.

CY Web must not reinterpret this domain as a formal multi-line quotation document.

Typical semantic shape:

```text
customer
+ item
+ quote date / salesperson
+ quantity-price breaks
+ notes
```

Examples of quantity-price breaks may include different unit prices for 10, 50 or 100 units of the same item for the same customer.

## SMART ERP boundary

Formal quotation documents already belong to SMART ERP. CY Web does not need a duplicate quotation-document authoring workflow such as quotation header + multiple quotation lines + document total.

Accordingly:

- SMART ERP remains authoritative for formal quotation documents;
- CY Web remains responsible for the lightweight customer-item quotation/price-history function used for quick business lookup and follow-up;
- CY Web should not create a parallel formal quotation numbering or document lifecycle;
- a future ERP Bridge may read/surface formal SMART ERP quotation information if that becomes useful, but CY Web is not the authoring system for those documents.

## Canonical modeling implication

The final canonical model should use a name that makes this distinction explicit, for example `customer_item_quotes` or another equivalent customer-item price-history term, rather than a generic `quotes` model that could be mistaken for a formal commercial document.

The record should reference the stable `customer_id` and `item_id`, while preserving the historical quoted price-break details needed for business lookup.

BD-006 formal-document snapshot semantics do not automatically turn this lightweight record into a formal quotation document. Its own history/immutability behavior will be decided separately during the remaining business review.
