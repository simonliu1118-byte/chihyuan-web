# Chihyuan Enterprise Management System

**CY Web** — 志遠企業管理系統的新一代全 Web 專案。

本 repository 為公開、source-visible proprietary 專案；原始碼可閱讀，但未授予開源使用、修改、散布或再授權權利。正式授權以本 repository 的 `LICENSE` 為準。

目前正在建立 Governance 2.0 與 Cloud/Web 新基準。舊 Google Apps Script／Google Sheets prototype 的完整歷史 source 保留於 Private legacy repository，不直接搬入本 Public repository；新系統會逐項比對其資料模型、ID、權限與操作行為後遷移。

產品方向：單一網站、RWD 基礎 + Adaptive UI；Desktop 維持高資訊密度與鍵盤效率，Mobile 依使用情境採卡片、Drawer、單欄表單、Bottom Sheet／全螢幕流程等呈現。中期身分系統方向為 CYCloud Identity；抽離前先重用 CYInvoice Cloud 既有相容帳號能力。
